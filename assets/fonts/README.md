# Fonts

These WOFF2 subsets are used only by the procedural sign textures and are embedded as
data URIs in the single-file build.

- **Pacifico** — SIL Open Font License 1.1 — https://fonts.google.com/specimen/Pacifico
- **Bebas Neue** — SIL Open Font License 1.1 — https://fonts.google.com/specimen/Bebas+Neue
- **Alfa Slab One** — SIL Open Font License 1.1 — https://fonts.google.com/specimen/Alfa+Slab+One

The font files remain under their respective OFL licenses.
